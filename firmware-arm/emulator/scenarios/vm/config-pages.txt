# The configuration pages, as a phone's browser fetches them.
#
# The head button is held at power-on; the phone joins the rabbit's network
# and asks for each page in turn, saying it takes gzip like any browser.
# tools/config-pages.sh runs this with --save-dir and checks every answer:
# the setup page plain with its fields filled, the stylesheet and the three
# fixed pages gzipped, each behind the right Content-Type (gzip_pages,
# 2026-11-18).

ap 02:00:5e:10:00:01 Terrier 6 open -52
tick 50
stop 90000

at 5000 get /a.htm
at 5000 get /s.css
at 5000 get /u.htm
at 5000 get /b.htm
