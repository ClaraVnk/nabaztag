# Review S-6 (2026-11-18): config mode is an open access point and cbhttp
# applied `?name=value` arguments from any request. Someone who joined it
# sends a new server on the stylesheet's URL, then on the save itself, with
# nobody touching the rabbit. With config_presence neither is taken: the
# stylesheet ignores its arguments, the save answers the error page because
# the head button is not held, the rabbit stays in config mode and the page
# written back to --eeprom still names the server it had.
# tools/config-presence.sh reads that page; a build without the step takes
# the server and joins the network (the control: expect-mode master fails,
# the rabbit is a station by then).
